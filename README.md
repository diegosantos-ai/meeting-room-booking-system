# RoomBook Corporate

Sistema de reserva de salas corporativas desenvolvido em Java, com foco em prática de Programação Orientada a Objetos e evolução incremental do projeto.

## Objetivo
Criar uma aplicação que permita registrar reservas de salas, listar ocupação e impedir conflitos de agendamento.

## Problema de negócio
Em muitas empresas, o controle de salas de reunião é feito de forma informal, o que pode gerar conflitos de uso, baixa visibilidade de ocupação e perda de tempo operacional.

## Escopo do MVP
- Cadastrar salas
- Registrar reservas
- Associar responsável à reserva
- Listar salas ocupadas
- Listar salas livres
- Impedir conflito de reserva no mesmo período
